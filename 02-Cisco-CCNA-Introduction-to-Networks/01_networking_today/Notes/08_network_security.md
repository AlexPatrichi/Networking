## 🎯 Objective 

Understand common network security threats and the solutions used to protect network devices, data, and communications from unauthorised access and attacks.

## 🧠 1.8.1 Security Threats

**Network security threats** are potential dangers that can compromise network devices, data, or services.

Securing a network involves using protocols, technologies, devices, and security practices to protect data and reduce threats.  

Threats can originate from **external** or **internal** sources.

### External Threats

**External threats** originate from outside an organisation's network.  

Many external network security threats today originate from the internet.

- Viruses and worms: Malicious software that can infect devices and spread across networks.
- Malware: Software designed to damage systems, steal information, or disrupt operations.
- Denial-of-Service (DoS) attacks: Attempts to make network services unavailable by overwhelming them with traffic or requests.
- Unauthorised access: Attackers attempting to gain access to systems or sensitive information.

Example: An attacker launches a DoS attack against a company's website, preventing customers from accessing its services. 

### Internal Threats

**Internal threats** originate from within an organisation and may be intentional or accidental.

- Employees accidentally deleting important files.
- Users accessing information without appropriate permission.
- Infected personal devices connecting to the company network.
- Employees intentionally stealing or exposing sensitive information.

Example: An employee unknowingly opens a malicious email attachment, infecting their computer and potentially exposing the company network to malware.

> NOTE: Internal users can accidentally or intentionally compromise network security. Their existing access to organisational resources makes internal threats particularly important.

## 🧠 1.8.2 Security Solutions

**Network security solutions** are technologies, policies, and practices used to protect network devices, data, and services.

Security should be implemented in multiple layers using different security solutions. If one security measure fails, others may still protect the network.  

This approach is called **defence in depth.**

### Home and Small Office Networks

Home networks and small businesses commonly use:

- Antivirus and anti-malware software: Detects, blocks, and removes malicious software.
- Firewalls: Monitor and control network traffic based on security rules.

Example: A home router uses a firewall to restrict unwanted incoming connections, while antivirus software helps protect the computers connected to the network.

### Business Networks

Larger organisations typically require additional security measures:

- Dedicated firewalls: Control traffic entering and leaving the network.
- Access Control Lists (ACLs): Permit or deny network traffic according to configured rules.
- Intrusion Prevention Systems (IPS): Detect and block suspicious or malicious network activity.
- Virtual Private Networks (VPNs): Provide secure, encrypted connections over untrusted networks, such as the internet.

Example: A company uses a firewall to control network access, an IPS to detect and block attacks, and a VPN to allow employees to connect securely while working remotely.

## 📌 Key Concepts to Remember

- External Threats: Security risks originating outside the organisation.
- Internal Threats: Security risks originating within the organisation.
- Malware: Malicious software designed to compromise systems or data.
- DoS Attack: An attack intended to make a service unavailable.
- Firewall: Controls network traffic according to security rules.
- ACL: Permits or denies traffic based on configured conditions.
- IPS: Detects and blocks malicious network activity.
- VPN: Provides encrypted communication over untrusted networks.

## 🔐 Security Relevance

Network security protects three essential principles:

- Confidentiality: Ensures sensitive information is accessible only to authorised users.
- Integrity: Protects information from unauthorised modification.
- Availability: Ensures network resources and services remain accessible when needed.

These principles form the CIA Triad.

**Key Takeaway:** Network security requires identifying internal and external threats and using multiple security measures to protect devices, data, and network services.
