## 🎯 Objective 

Understand how modern networking technologies and trends are changing the way people communicate, work, and access information.  

## 🧠 1.7.1 Recent Trends

Network technologies continue to evolve as people increasingly rely on internet connectivity for work, education, and everyday activities.

These trends increase the demand for reliable, secure, and high-speed networks.

## 🧠 1.7.2 Bring Your Own Device (BYOD)

**Bring Your Own Device (BYOD)** allows employees or students to use their personal devices to access an organisation's network and resources.

- Includes personal laptops, smartphones, and tablets.
- Allows users to work or study from different locations.
- Requires appropriate network security controls.

Example: A university student connects their personal laptop to the university Wi-Fi to access online learning resources.

Personal devices must follow the organisation's security policies.

## 🧠 1.7.3 Online Collaboration 

**Online collaboration** allows people in different locations to work together and communicate over a network.

- Supports messaging, file sharing, and teamwork.
- Allows multiple users to work on shared documents.
- Reduces the need for everyone to be in the same physical location.

Example: Employees use Microsoft Teams to communicate and collaborate on a shared project while working from different locations.

## 🧠 1.7.4 Video Communication

**Video communication** allows people to communicate using live video and audio over a network.

- Supports remote meetings and online learning.
- Requires sufficient bandwidth and stable connectivity.
- Benefits from Quality of Service (QoS) to reduce delays and interruptions.

Example: Students attend online classes using video conferencing to communicate with their tutor and classmates, ask questions, and learn remotely.

## 🧠 1.7.5 Video - Cisco Webex for Huddles

**Cisco Webex** is a collaboration platform that supports video meetings, messaging, and teamwork.

A **huddle space** is a small meeting area designed for quick team discussions and video collaboration.

Example: A small group of employees uses Cisco Webex equipment in a meeting room to join a video call with colleagues working remotely.

## 🧠 1.7.6 Cloud Computing 
**Cloud computing** provides access to applications, storage, and computing resources over a network, typically through the internet.

- Allows users to access resources from different locations.
- Can reduce hardware and maintenance costs by using cloud-based resources instead of maintaining everything locally.
- Supports flexible storage and computing capacity.

Example: A student stores coursework in Microsoft OneDrive and accesses it from their laptop or smartphone.

### Types of Cloud Computing

1. Public Cloud: Cloud services offered to customers by a provider over shared infrastructure.
    > Example: A company uses Microsoft Azure to host its website without maintaining its own physical servers.

2. Private Cloud: Cloud infrastructure dedicated to a single organisation.
    > Example: A bank uses a private cloud to run internal applications and manage sensitive financial data.

3. Hybrid Cloud: Combines private and public cloud environments.
    > Example: A hospital uses a private cloud for sensitive patient records and a public cloud for less sensitive applications.

4. Community Cloud: Cloud infrastructure shared by organisations with similar requirements.
    > Example: Several hospitals share a community cloud to support healthcare applications while meeting common security and regulatory requirements.

## 🧠 1.7.7 Technology Trends in the Home

**Smart home technology** connects household devices to a network, allowing them to communicate and be monitored or controlled.

- Includes smart televisions, lighting, thermostats, and security cameras.
- Often uses Wi-Fi or other wireless technologies.
- Allows remote monitoring and automation.

Example: A homeowner uses a smartphone application to control smart lights and view a home security camera.

## 🧠 1.7.8 Powerline Networking

**Powerline networking** uses existing electrical wiring inside a building to carry network data.

- Uses powerline adapters connected to electrical sockets.
- Can extend network connectivity where Wi-Fi signals are weak.
- Performance depends on the building's electrical wiring.

Example: A homeowner connects one powerline adapter to the router downstairs and another to a computer upstairs using Ethernet cables. The adapters communicate through the home's electrical wiring.

Powerline networking extends the existing home network using electrical wiring instead of a long Ethernet cable.

## 🧠 1.7.9 Wireless Broadband

**Wireless broadband** provides internet connectivity using wireless communication rather than a wired connection to the premises.

> NOTE: A Wireless Internet Service Provider (WISP) is an ISP that delivers internet access using wireless technology instead of a wired connection to the customer's premises. 

- Useful where traditional wired broadband is unavailable.
- Can use cellular networks or fixed wireless technologies.
- Performance depends on signal strength, coverage, and network capacity.

Example: A household in a rural area uses a WISP to access the internet. A wireless tower communicates with an antenna installed on the house, providing internet connectivity without a fibre or cable connection.


## 📌 Key Concepts to Remember

- BYOD : Use personal devices for work or study
- Online Collaboration: Work together across different locations
- Video Communication: Communicate using live video and audio
- Cloud Computing: Access computing resources over a network
- Smart Home: Connect and control household devices
- Powerline Networking: Carry network data over electrical wiring
- Wireless Broadband: Provide internet access through wireless technology

## 🔐 Security Relevance

- Modern networking trends introduce new security challenges.
- BYOD: Personal devices may introduce security risks to organisational networks.
- Online Collaboration: Shared files and communications require appropriate access controls.
- Cloud Computing: Data and applications require secure authentication and access management.
- Smart Homes: Connected devices should use strong passwords and receive security updates.
- Wireless Broadband: Wireless connections require appropriate encryption and security measures.

**Key Takeaway:** Modern networking technologies make communication and access to information more flexible, but they also increase the importance of reliable connectivity and network security.
