## 🧠 1.3.1 Network Representations

Network engineers use **network diagrams** to represent devices, connections, and the overall structure of a network.

Instead of drawing every device in detail, diagrams use standard **symbols** to make networks easier to understand.

### Common Network Symbols

- **End Devices:** Computers, laptops, servers, printers, and smartphones.
- **Switches:** Connect devices within a local area network (LAN).
- **Routers:** Connect different networks and forward data between them.
- **Wireless Access Points:** Provide wireless network connectivity.
- **Network Links:** Lines representing wired or wireless connections.
- **Network Clouds:** Represent networks such as the internet without showing their internal details.

### Important Networking Terms

- **Network Interface Card (NIC):** Hardware that allows a device to connect to a network.
- **Physical Port:** A connection point on a networking device where a cable can be attached.
- **Interface:** A connection point (Wired or Wireless connection) through which a device communicates with a network.

## 🧠 1.3.2 Topology Diagrams

A **network topology** describes how devices and connections are arranged within a network.

Network engineers use **two different views of the same network**.

### Physical Topology

A **physical topology diagram** shows the actual location of network devices and how they are physically connected.

It may include:

- Device locations, such as rooms and buildings.
- Cable connections between devices.
- Physical ports used for connections.
- Network equipment such as routers and switches.

**Example:** A university network diagram showing switches installed in different buildings and the cables connecting them.

⚠️ Focuses on cables, ports, and equipment.  
⚠️ Useful for installation and cable troubleshooting  

### Logical Topology

A **logical topology diagram** shows how devices communicate across a network, regardless of their physical location.

It may include:

- IP addresses and network information.
- Connections between different networks.
- How network traffic is forwarded.
- Logical relationships between devices.

**Example:** A diagram showing how a student's laptop communicates with a university server through switches and routers.

⚠️ Focuses on network connections and data paths.    
⚠️ Useful for configuration and network troubleshooting.  

## 📌 Key Concepts to Remember

- Network diagrams use symbols to represent devices and connections.
- A NIC allows a device to connect to a network.
- Physical ports and interfaces provide connection points for network communication.
- Physical topology diagrams show how a network is physically built.
- Logical topology diagrams show how the network is organised for communication.
- Both types of diagrams help network engineers document, manage, and troubleshoot networks.

## 🔐 Security Relevance

Understanding network diagrams helps cybersecurity professionals identify network infrastructure and potential security risks.

- **Network Visibility:** Identify devices, connections, and important network resources.
- **Security Planning:** Understand where firewalls and other security controls are positioned.
- **Troubleshooting:** Locate devices and connections involved in network problems.
- **Incident Response:** Use topology diagrams to investigate how suspicious traffic may travel between networks.
- **Network Documentation:** Maintain accurate records of network infrastructure to support secure management.
